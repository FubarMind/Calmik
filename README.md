# Дыхательные практики

Веб-приложение для обучения правильным техникам дыхания с целью снижения стресса, улучшения концентрации и поддержки медитативных практик.

## Функциональность

- Таймер дыхания с визуализацией
- Три техники дыхания:
  - 4-7-8 (для снижения стресса)
  - Квадратное дыхание
  - Глубокое дыхание
- Визуальная анимация процесса дыхания
- Темная/светлая тема
- Сохранение настроек в браузере

## Установка и запуск

1. Скачайте или клонируйте репозиторий
2. Откройте файл `index.html` в любом современном браузере

## Технические детали

- Чистый HTML, CSS и JavaScript без зависимостей
- Адаптивный дизайн
- Поддержка всех современных браузеров
- Локальное хранение настроек

## Использование

1. Выберите технику дыхания из выпадающего списка
2. Нажмите кнопку "Начать"
3. Следуйте визуальным подсказкам и таймеру
4. При необходимости используйте кнопку "Остановить"

## Требования

- Современный веб-браузер с поддержкой CSS3 и JavaScript ES6
- Включенный JavaScript
- Разрешение на использование localStorage
